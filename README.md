# RBMI Campus Events

This project is a simple frontend website created for displaying college events of RBMI (Rakshpal Bahadur Management Institute).

The website allows students to:
- View upcoming events
- View past events
- See organizer information
- Navigate easily between different sections

The project focuses on clean design, simple navigation and user-friendly layout.

---

## Technologies Used

- HTML5
- CSS3
- Basic JavaScript (for simple interactions)

---

## Website Pages

The project contains the following pages:

1. Home Page – Main landing page with navigation and event sections.
2. Events Page – Allows users to choose between upcoming and past events.
3. Upcoming Events – Shows upcoming college events.
4. Past Events – Displays previously held events.
5. Signup Page – Allows students to register.
6. Login Page – Allows users to log in.
7. About Page – Information about RBMI institute.
8. Organizer Page – Shows event organizer details.

---

## Project Purpose

The main goal of this project is to create a simple event portal where students can easily view and access college event information.

This project was developed as a frontend practice project.
